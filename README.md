# org.nsoft.idempiere.autoprice
IDempiere Plugin to Generate auto sales pricelist based on Purchase Order transaction.

For businesses—particularly trading businesses dealing with fluctuating market prices—a system is needed that can automatically update selling prices based on purchase costs. We can apply a specific percentage or a markup to the purchase price.

This plugin applies price updates at the product level, allowing for flexible markup adjustments for each individual product. It also features price rounding, ensuring that prices do not end up looking odd or awkward—particularly important for the Indonesian market.

Changes to sales price list are recorded or stored in the Price History table, which can be used for analysis or as evidence of the changes.
